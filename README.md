# Maestro Aero - Official Web Platform

Modern aviation travel, flight search, seat bidding, and loyalty rewards platform for **Maestro Aero** by Maestro Group.

🌐 **Domain**: [maestroaero.maestrogroup.world](https://maestroaero.maestrogroup.world)  
📦 **Tech Stack**: Pure HTML5, Vanilla CSS3, JavaScript (ES6+)

## 🌟 Key Features

1. **Interactive Flight Search Engine**:
   - One Way and Round Trip selection with airport swap (Dubai DXB ⇄ Dhaka DAC).
   - Live search simulation displaying real flight card: **Mahan Air W51003 (Boeing 777-200ER)** with Economy (৳ 45,005.59) and Business (৳ 305,015.89).
2. **Proprietary Seat Bidding**:
   - Interactive modal enabling travelers to bid on seat upgrades and economy tickets.
3. **Maestro & Miles Loyalty Club**:
   - Comprehensive loyalty tiers showcase with digital Bronze card mockup featuring *Iftikhar Alam*, member ID `9584 1561 6178`, points balance, and QR pass.
4. **App Showcase & Downloads**:
   - App screenshots and Google Play / App Store badges with dynamic QR code scanner.
5. **Account Deletion Portal**:
   - Dedicated verification form for account erasure requests (Full Name, Contact, Passport Number, Reason).
6. **Compliant Legal Documentation**:
   - Comprehensive Privacy Policy and Terms of Service.

## 🚀 Deployment

Since this is a static website, it can be deployed on:
- **cPanel / Web Hosting**: Upload files to `public_html/maestroaero`
- **Linux VPS / Nginx**: Clone repository to `/var/www/maestroaero`
- **Cloudflare Pages / Vercel**: Connect GitHub repository `coderblower/maestroaero.maestrogroup.world` for automatic CI/CD.
